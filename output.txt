Model: Code_1_Ingestion and Feature Engg

1) Input Data Elements
- work.txn_raw: acct_id, amt, delinquency, merchant_cat, txn_dt
- work.acct_master: acct_id, limit, open_dt, product_cd, rate_apr
- work.cust_master: acct_id, cust_id, seg, state
- work.base_join: (attributes: unknown)

2) Code Details
a. Purpose of the code: Ingest raw transaction and master data, create monthly behavioral and risk features for credit risk modeling.
b. Data transformation logic implemented
- Generate mock source tables work.txn_raw, work.acct_master, and work.cust_master if they do not exist with synthetic data.
- Aggregate transactions monthly per account in work.txn_mth table, computing sums of positive and negative spend, delinquency hits, transaction counts, and average absolute transaction amount.
- Join distinct accounts from txn_raw with account master, customer master, and monthly transaction aggregates to create a base feature table work.base_join with coalesced feature values.
- Calculate rolling balances, utilization ratios, utilization flags, debt-to-income proxy, delinquency proxies, and point-in-time PD, LGD, EAD estimates in work.risk_base dataset.
c. Calculation Logic implemented
- Monthly aggregation: asof_mth = start of transaction month; spend_pos = sum of positive amounts; spend_neg = sum of negative amounts; delinq_hits = count of delinquency flags; txn_cnt = transaction count; avg_txn_amt = average absolute transaction amount.
- Balance rolling: first month balance = min(limit, spend_pos - repayments); subsequent months balance = max(0, min(limit, lag(balance) + spend_pos - repayments)).
- Utilization = balance divided by limit (with limit at least 1).
- High utilization flag if util > 0.8.
- DTI proxy = min(2, 0.2 + 1.2*util + 0.1*(txn_cnt>20)).
- Days past due accumulates by 30 days if delinquency hits > 0 else reduced by 15 days but not below zero.
- PD point = capped at 0.25, computed as 0.02 + 0.15*util + 0.05 if days_past_due>0 + 0.02 if seg='SME'.
- LGD point capped at 0.75, base 0.35 plus 0.2 if product in ('PL','HELOC') plus 0.1 if state in ('FL','TX','CA').
- EAD point = balance times (1 + 0.05 if product='CARD' + 0.10 if product='HELOC').

3) Output Data Elements
- work.txn_mth: acct_id, asof_mth, avg_txn_amt, delinq_hits, spend_neg, spend_pos, txn_cnt
- work.base_join: acct_id, asof_mth, avg_txn_amt, cust_id, delinq_hits, limit, open_dt, product_cd, rate_apr, repayments, seg, spend_pos, state, txn_cnt
- work.risk_base: acct_id, asof_mth, avg_txn_amt, balance, cust_id, days_past_due, delinq_hits, dti_proxy, ead_point, high_util, lgd_point, limit, open_dt, pd_point, product_cd, rate_apr, repayments, seg, spend_pos, state, txn_cnt, util
- work.acct_master: (attributes: unknown)
- work.cust_master: (attributes: unknown)
- work.txn_raw: (attributes: unknown)

a. Purpose of the code: To stage credit risk data by asset class and risk stage, calculate proxies for Expected Credit Loss (ECL), Risk Weighted Assets (RWA), and interest income, followed by portfolio aggregation and preparing a final risk view table.

Model: Code_4_Final Regulatory/Finance Report

1) Input Data Elements
- work.risk_base: (attributes: unknown)
- work.stressed_metrics: asof_mth, cet1_need, ead, ecl_base, ecl_stress, nii_base, nii_stress, rwa_base, rwa_stress, scenario
- work.base_s: (attributes: unknown)

2) Code Details
a. Purpose of the code: Generate a final regulatory and finance report showing capital ratios, liquidity coverage ratio (LCR), earnings signals, and management actions under base and severe stress scenarios.
b. Data transformation logic implemented
- Check existence of work.risk_base and work.stressed_metrics datasets.
- Create work.balance_sheet_params with monthly balance sheet assumptions (common_equity_tier1, addl_tier1, hqla, net_outflows_30d) having random variations over months from Jan 2024 to Aug 2024.
- From work.stressed_metrics extract BASE and SEVERE scenarios, join them side-by-side on asof_mth into work.base_s with renamed columns for base and severe scenarios.
- Join work.base_s with work.balance_sheet_params by asof_mth and calculate final report metrics including capital amounts, ratios, LCR, earnings, and management action signal, output to work.final_reg_report.
- Print work.final_reg_report with formatted labels and numeric formats.
- Export work.final_reg_report to CSV file named 'final_reg_report.csv'.
c. Calculation Logic implemented
- common_equity_tier1, addl_tier1, hqla, net_outflows_30d values generated randomly per month (intnx monthly intervals).
- LEFT JOIN stressed_metrics filtering BASE and SEVERE scenarios on asof_mth.
- Calculate cet1_cap = common_equity_tier1.
- Calculate tier1_cap = common_equity_tier1 + addl_tier1.
- Calculate CET1 ratio base = common_equity_tier1 / rwa_base.
- Calculate CET1 ratio stress = (common_equity_tier1 - cet1_need_severe) / rwa_severe.
- Calculate LCR = hqla / net_outflows_30d.
- Determine management action: if ecl_severe > 1.7 * ecl_base then 'Increase overlays', else if cet1_need_severe > 0.10 * rwa_severe then 'Consider RWA optimization', else 'Within appetite'.

3) Output Data Elements
- work.balance_sheet_params: addl_tier1, asof_mth, common_equity_tier1, hqla, net_outflows_30d
- work.base_s: asof_mth, cet1_need_severe, ead_base, ecl_base, ecl_severe, nii_base, nii_severe, rwa_base, rwa_severe
- work.final_reg_report: asof_mth, cet1_cap, cet1_ratio_base, cet1_ratio_stress, ecl_base, ecl_severe, hqla, lcr, mgmt_action, net_outflows_30d, nii_base, nii_severe, rwa_base, rwa_severe, tier1_cap
